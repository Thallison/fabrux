# Documentacao por Modulo

## Objetivo

Organizar regras e funcionalidades por contexto de negocio para facilitar manutencao e evolucao incremental.

## Modulos

- base/README.md
- cadastros/README.md
- Producao/README.md
- relatorios/README.md
- seguranca/README.md

## Como Atualizar

Ao alterar um modulo:

1. atualizar o README do modulo
2. registrar novas rotas/permissoes
3. registrar impactos em testes
4. ajustar referencias cruzadas quando necessario
