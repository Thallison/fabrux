# Documentacao por Modulo

## Objetivo

Organizar regras e funcionalidades por contexto de negocio para facilitar manutencao e evolucao incremental.

## Modulos

- base/README.md
- cadastros/README.md
- orcamento/README.md
- Producao/README.md
- relatorios/README.md
- seguranca/README.md

## Como Atualizar

Ao alterar um modulo:

1. atualizar o README do modulo
2. registrar novas rotas/permissoes
3. registrar impactos em testes
4. registrar impacto em padroes frontend quando houver componentes compartilhados
5. ajustar referencias cruzadas quando necessario

## Referencias Cruzadas Importantes

- docs/arquitetura.md
- docs/padroes-frontend.md
- docs/testes.md
