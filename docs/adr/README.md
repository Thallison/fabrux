# ADRs (Architectural Decision Records)

## Objetivo

Registrar decisoes arquiteturais importantes, seus motivos e impactos.

## Como usar

1. Crie um arquivo numerado sequencialmente.
2. Descreva contexto, decisao e consequencias.
3. Relacione PRs e documentos impactados.

## Padrao de Nome

- 0001-titulo-curto.md
- 0002-titulo-curto.md

Use o template em docs/templates/adr-template.md.
